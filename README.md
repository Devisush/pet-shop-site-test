# pet-shop-site-test

# 🐾 Тестовый веб-сайт «Магазин для питомцев»

Простой, отзывчивый и интерактивный многостраничный сайт зоомагазина с интеграцией полезных услуг и работающей системой корзины. Проект создан на чистом стеке веб-технологий (Vanilla HTML/CSS/JS) без использования сторонних фреймворков.

## 🚀 Функционал сайта

*   **Главная страница:** Каталог популярных товаров, информационный блок «О нас» и контакты.
*   **Блог для хозяев:** Полезные иллюстрированные статьи с адаптивной версткой.
*   **Интерактивная корзина:** Сохранение выбранных товаров в локальное хранилище браузера (`localStorage`). Товары не пропадают при переходе между страницами или обновлении вкладки. Подсчитывается общее количество и финальная сумма.
*   **Страница услуг:** Карточки сервиса груминга и онлайн-форма записи на процедуры.
*   **Умная навигация:** Плавный скролл к секциям на главной странице и кастомная кнопка «Назад / На главную» с анимацией.

## 🛠️ Используемые технологии

*   **HTML5** — семантическая разметка (теги `header`, `nav`, `main`, `section`, `article`, `footer`).
*   **CSS3** — Flexbox и Grid Layout для построения сеток, CSS Transitions для плавных анимаций, Media Queries для мобильной адаптивности.
*   **JavaScript (ES6)** — динамический рендеринг элементов, работа со встроенным хранилищем данных `localStorage`, обработка событий клика и отправки форм.

## 💻 Инструкция по запуску

1. Склонируйте репозиторий или скачайте все 6 файлов в одну общую папку на компьютере.
2. Для просмотра сайта просто дважды кликните по файлу `index.html`. Он откроется в любом современном браузере (Chrome, Edge, Safari, Firefox).
3. Для полноценной разработки рекомендуется открывать проект через редактор кода (например, **VS Code**) с использованием расширения **Live Server** для автоматического обновления страниц при сохранении кода.

## 🎨 Особенности стилизации

*   **Основная палитра:** Теплый оранжевый `#ff9f43` (акценты), дружелюбный зеленый `#10ac84` (кнопки, корзина), глубокий темно-серый `#2c3e50` (шапка и подвал).
*   **Изображения:** В каталоге используются адаптивные изображения с эффектом легкого увеличения (`scale(1.05)`) при наведении курсора на карточку товара.
